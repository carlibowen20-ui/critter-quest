# Critter Quest 🦋🐞

A cheerful animal-catching adventure game for young kids. Tap critters as they wander, fill your sticker book, complete quests, and unlock new habitats.

## Features

- **5 habitats to unlock** — Garden, Meadow Pond, Whispering Forest, Jungle Canopy, Coral Reef
- **40+ animals** to discover, each with a fun fact
- **Hidden rare critters** — golden ladybug, rainbow fish, white stag, rainbow macaw, magic seahorse
- **Sticker book** that fills up as you catch new species
- **Rotating quests** with star rewards
- **Two mini-games** — Memory Match and Count the Critters
- **Difficulty grows** with experience: faster critters, harder quests, bigger numbers
- **Saves automatically** in the browser

## Play it

Just open `index.html` in any modern browser. Works on tablets, phones, and computers.

### Host it free on GitHub Pages

1. Push this folder to a new GitHub repo.
2. In the repo, go to **Settings → Pages**.
3. Under "Build and deployment", choose **Deploy from a branch** and pick `main` / root.
4. After a minute it will be live at `https://<your-username>.github.io/critter-quest/`.

## Built for

A 4-year-old who loves animals and bugs. Designed to grow with the player — gentle at first, then progressively more challenging.
